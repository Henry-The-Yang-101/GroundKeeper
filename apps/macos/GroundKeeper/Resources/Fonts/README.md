# Fraunces

The unmodified Roman variable font is bundled for offline use. Fraunces is
designed by Phaedra Charles and Flavia Zimbardi of Undercase Type and licensed
under the SIL Open Font License 1.1; see `Fraunces-OFL.txt`.

Source: https://github.com/google/fonts/tree/main/ofl/fraunces
Designer specimen: https://fraunces.undercase.xyz/

`VaultTypography` registers the font only in the app process. Headings use
Fraunces with medium weight; controls and transaction values use the macOS
system font. No system font installation or remote font request is needed.
